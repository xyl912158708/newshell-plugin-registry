# 对象存储（Object Storage）

阿里云 OSS 与 S3 兼容服务（MinIO、AWS S3、R2、COS、OBS、B2 等）通用对象存储浏览器。**全部业务集中在插件的一个主页内**：连接管理、文件浏览、传输任务、文件预览都无需离开本页。

当前版本：**1.2.1**（修复深色主题标题不可见、HTML/3D 预览空白、窄窗口列表列溢出；弹窗密度、错误提示文案与按钮文案统一）。

## 功能

- **连接管理**：连接以列表形式管理（可任意多个），内置服务商预设（阿里云 OSS、AWS S3、MinIO、Cloudflare R2、腾讯云 COS、华为云 OBS、Backblaze B2、自定义）；新建/编辑弹窗内可直接「测试连接」，自动记住上次使用的连接。
- **对象浏览**：服务端分页（continuation token）+ 虚拟滚动（200+ 对象流畅滚动），工具栏前缀搜索、按文件夹下钻、面包屑导航。
- **传输任务中心**：统一查看上传/下载/批量复制任务进度；可取消；**失败下载会持久化落盘**，重启应用后仍可一键重试。
- **分片上传**：文件 ≥16MB 自动走分片上传（8MB/片、3 并发），小文件单次 PUT；上传进度逐片更新。
- **多选批量操作**：勾选多个对象批量删除、批量下载、批量复制/移动到指定前缀。
- **预签名链接分享**：15 分钟 – 7 天有效期可选，一键复制 URL。
- **文件预览**：图片、文本、Markdown（渲染）、HTML（消毒后内嵌）、3D 模型（STL/OBJ/GLB，WebGL2）可直接在页面内预览；视频/音频/PDF/Office 宿主 CSP 限制内嵌播放，会给出可点开的预签名链接（Office 附带在线查看链接）。

## 界面与主题

界面使用 **Vue 3 + Pico.css**（vendor/ 内含两者的官方发行文件与 MIT 许可证）。注意：宿主禁止插件页编译模板（CSP 无 `unsafe-eval`、子资源请求被拦截），Vue 与 Pico 均以**内联副本**方式引入页面，vendor/ 保留原始发行文件备查。页面默认深色（与 NewShell 主界面一致），右上角可切换浅色，偏好会持久化；宿主与插件页跨源、系统媒体查询又只跟随操作系统，均无法可靠反映应用内主题设置，故不做自动跟随。

## 架构与数据安全

- **协议交互在主进程执行**：插件启用时在 NewShell 主进程内启动一个无状态本地代理（`127.0.0.1:17931`，仅监听本机）。工具页把「当前连接配置 + 结构化操作」发给代理；全部 SigV4 签名、S3 协议请求与 XML 解析都在 Node 侧（https + crypto）完成，**渲染页不做签名、不直连存储服务**，因此无需为 Bucket 配置 CORS。代理不保存任何配置与状态，配置随请求传入、用后即弃。
- **密钥存放**：连接配置（Endpoint / Region / AK / SK）只保存在 NewShell 本地的插件数据中（`<用户数据>/data/plugins/object-storage/plugin-data.json`），不经过任何第三方。它在「保存失败下载的重试信息」里也会携带同样的连接配置快照。
- 插件权限仅 `host_access`（运行主进程代理）与 `network`（代理访问存储服务端点）。

## 使用方法

1. 在 NewShell 的「插件」管理中启用本插件并授予权限。
2. 从顶部「工具」菜单打开「对象存储」。
3. 点「＋ 新建连接」：选服务商预设（会自动带入 Endpoint / Region / 寻址方式），填名称、Access Key、Secret Key，可填默认 Bucket；建议先「测试连接」再保存。
4. 左侧列表点选连接即可浏览；双击文件夹下钻；行尾按钮可预览/下载/复制链接/重命名/删除，勾选多项后出现批量操作栏。

## 已知限制

- 批量复制/移动逐个对象执行 CopyObject，单个对象上限 5GB。
- 下载文件在页面内整文件装配后保存（超大文件请用 `rclone`/`mc` 等专用工具）；失败下载可重试。
- 3D 预览仅支持自包含的 glTF（.glb 或内嵌资源的 .gltf）；依赖外部 .bin/贴图的文件会给出提示。
- 阿里云 OSS 等服务请使用其 **S3 兼容端点**并关闭 Path-Style（如 `https://s3.oss-cn-hangzhou.aliyuncs.com`）；本机 17931 端口被占用时代理无法启动。

## 开发说明

- `index.html` 由 `index.src.html` 构建生成：构建脚本将 Pico.css 与 Vue 的发行文件内容分别替换 `<!-- __PICO_CSS__ -->`、`<!-- __VUE_JS__ -->` 占位符。修改界面请改 `index.src.html` 后重新生成，不要直接编辑 `index.html`。
- `manifest.json`：插件清单（工具页入口 `index.html`，权限 `host_access` + `network`）。
- `main.js`：主进程无状态代理（SigV4 签名、结构化操作、上传/下载字节流转发）。
